# IDs fictícios

Todos os valores abaixo devem ser substituídos por pessoas autorizadas no ambiente de teste. O mesmo ID pode ter papel de aprovador e de Contas a Pagar; preserve o vínculo se isso fizer parte do seu processo. Os nomes exibidos também são exemplos e podem ser alterados no modal e no código de extração da decisão.

- `UDEMO000001`: HTTP Request, Extrair Decisão (Aprovado/Negado)
- `UDEMO000002`: HTTP Request, Extrair Decisão (Aprovado/Negado), Aprovação Contas a Pagar, Abrir DM Contas a Pagar
- `UDEMO000003`: HTTP Request, Extrair Decisão (Aprovado/Negado)
- `UDEMO000004`: Extrair Decisão (Aprovado/Negado), Abrir DM Contas a Pagar - Responsável 2, Aprovação Contas a Pagar - Responsável 2
